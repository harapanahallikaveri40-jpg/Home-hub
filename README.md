# Smart Home IoT Control System

## Project Overview

The **Smart Home IoT Control System** is a responsive web-based dashboard designed to help users monitor and control smart home devices from a single interface.

Users can manage lights, air conditioners, fans, and other smart devices, create automation routines, monitor energy consumption, and control devices room by room.

This project focuses on providing a simple, modern, and user-friendly smart home management experience.

## Features

- **Dashboard:** View an overview of connected devices and their current status.
- **Device Management:** Turn smart devices ON/OFF and manage connected devices.
- **Brightness Control:** Adjust smart light brightness.
- **Temperature Control:** Control air conditioner temperature.
- **Room Management:** Search and filter devices by room.
- **Smart Automations:** Create, enable, disable, and delete automation routines.
- **Smart Scenes:** Use predefined scenes such as Good Morning, Away Mode, Movie Night, and Good Night.
- **Energy Monitoring:** View simulated energy consumption information.
- **Settings:** Manage dashboard preferences.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Local Storage:** Saves device settings and automation data in the browser.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click and select **Open with Live Server**.
5. The Smart Home dashboard will open in your browser.

You can also open `index.html` directly in any modern web browser.

## How to Use

1. Open the dashboard to view the smart home overview.
2. Navigate to the Devices section.
3. Turn devices ON or OFF using the toggle buttons.
4. Adjust light brightness and AC temperature.
5. Add or remove devices.
6. Create automation routines in the Automations section.
7. Select smart scenes to control multiple devices.
8. Visit the Energy section to view energy information.
